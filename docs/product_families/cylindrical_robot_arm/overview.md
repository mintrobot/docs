# Cylindrical Robot Arm

## What It Is

A cylindrical robot arm is a robot built around linear vertical motion and rotational motion, forming a simple and highly practical cylindrical working structure.

Compared with articulated robot arms that have elbow joints, a cylindrical robot arm can often use its reachable space more directly and with fewer interference points. This makes it especially useful in narrow installations or applications where elbow interference becomes a practical limitation.

## Key Advantages

The practical strengths of a cylindrical robot arm are not just in its shape, but in how easily it can be deployed and used.

- it can often cover a wider usable working range than an articulated arm in the same constrained area
- it has less elbow interference, which makes it easier to apply in narrow or obstructed spaces
- its vertical up-and-down motion is intuitive, making task setup and point programming easier to understand
- its simple mechanical structure reduces failure points and makes maintenance easier

For these reasons, the cylindrical robot arm is well suited to applications that value compact installation, straightforward motion logic, and practical reliability.

## Models

The current cylindrical robot arm offering is based on the `PSC03` platform.

`PSC03` stands for `Pal Service Cylindrical`, with a payload class of `3 kg`.

The currently documented model is `PSC03X4`.

| Model | Axis Count | Structure | Description |
| --- | --- | --- | --- |
| `PSC03X4` | 4-axis | `R-P-R-R` | Base cylindrical configuration with SCARA-like simplicity |

## Model Differentiation

`PSC03X4` is the most basic configuration of the `PSC03` platform and is closest in form to a SCARA-style working concept.

It uses an `R-P-R-R` structure and is intended for applications that benefit from simple cylindrical motion without added wrist complexity.
